Na edição de uma categoria, o administrador do sistema tem **Comparar com o modelo**: mostra as diferenças entre a categoria do grupo e o modelo de mesmo nome (o do catálogo de modelos; sem ele, a categoria global), para decidir se publica as alterações como nova versão do modelo.
- Por área: **Categoria** (descrição, atualizável, situação, lista aberta, registro único, revisão…), **Campos** (tipo, descrição, padrões, ordem, papel no gráfico, unidade…), **Subcategorias** e **Consultas** escritas à mão (SQL, descrição, parâmetros e colunas do resultado).
- Cada linha diz se é **diferente**, **só no grupo** (entra no modelo ao publicar) ou **só no modelo** (sai do modelo ao publicar). SQL longo abre ao tocar.
- A conexão do ERP não entra na comparação (não vai para o modelo). As consultas automáticas também não (são geradas de novo a partir dos campos).
- Depois de comparar, **Publicar no catálogo** já vem com o "Para que serve" e as frases de exemplo do modelo atual, para não apagá-los.
