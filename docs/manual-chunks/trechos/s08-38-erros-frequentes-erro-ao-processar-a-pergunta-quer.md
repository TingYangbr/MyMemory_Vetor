Sintoma: Erro ao processar a pergunta: Query #N "nome": …
Causa e solução: Falha no SQL da query N. Abrir "ver etapas" para ver o SQL e os parâmetros; corrigir a query ou os parâmetros em Painel Owners → Categorias.
